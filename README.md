# StackOps
StackOps is a full-stack team collaboration and project management platform built using the PERN stack. It allows teams to manage tasks, organize workflows, and collaborate in real time through a clean and user-friendly interface.

The application includes features like role-based access control, task management with kanban boards, activity tracking, and real-time updates using WebSockets. It is designed with a strong focus on backend architecture, scalability, and practical real-world use cases.

This project reflects my focus on building production-ready applications while continuously improving my full-stack development skills.
